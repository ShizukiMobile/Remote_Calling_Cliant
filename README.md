# Remote_Calling_Cliant
2台以上のパソコンを「ルームID」で相互に接続し、端末を呼び出すことができます。

# 【使用方法】  
まず、https://shizukimobile.github.io/Remote_Calling_Cliant/ にアクセスします。  
呼び出したいパソコン間で同じルームIDを入力し、同じルームに参加してください。  
「呼び出し」ボタンを押すと、呼び出し操作を行った端末以外のすべての端末を呼び出します。  
(現時点では、呼び出し相手を指定する機能はありません)

〈現在時刻表示について〉  
このサイトでは、日時はデバイスの日時を取得して表示しています。  
そのため、デバイスの日時がズレていると正しい日時を表示しません。  

# 【推奨環境】
・Google Chrome 84以降
・Microsoft Edge 84以降
※その他Chromium系のブラウザでは、Chromium 84以降をベースとしたブラウザ
・Firefox 126以降
・Opera 70以降
・Samsung Internet Browser (Android版) v14.0以降
・macOS Ventura以降
・iOS/iPadOS 16.4以降
〈注意〉
・Internet ExplorerならびにMicrosoft Edgeの「IEモード」は非推奨です。
・macOSならびにiOS、iPadOSではSafariの使用をおすすめします。
・PCやスマホなどデバイスのタイプにかかわらず使用できますが、スマホでは表示が小さくなることがあります。
お手数ですが、必要に応じてページを拡大してご利用ください。
・これ以前のブラウザやOSでも動作することがありますが、一部の機能が使用できないことがあります。
また、端末の設定や状態によっては一部の機能が正常に動作しないことがあります。
・一部の機能は、ページをフォアグラウンドで表示している場合のみ動作します。
・iOS 16.4から18.3では、ホーム画面に作成したショートカットからアクセスすると一部の機能が正常に動作しないことがあります。
